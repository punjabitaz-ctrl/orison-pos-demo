# Orison POS - live demo

A working preview of Orison POS, the offline-first point of sale for Orison Electronics, running on a sample shop.

**Open it:** https://punjabitaz-ctrl.github.io/orison-pos-demo/

Everything runs in your browser. Nothing is sent anywhere and nothing touches a real store. Each browser keeps its own copy of the shop; the yellow DEMO tab has a **Reset demo data** button.
